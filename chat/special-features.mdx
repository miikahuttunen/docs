## Data Analysis

When working with spreadsheets, Realm can write code to analyze the data and draw graphs.

### How to Use Data Analysis

<Steps>
  <Step title="Attach a Spreadsheet">
    Select "Attach file" and attach a spreadsheet (XLSX, XLS, or CSV).
  </Step>
  <Step title="Enable Data Analysis">
    Click "Data Analysis" to enable the feature.
  </Step>
  <Step title="Prompt for Analysis">
    Ask Realm to analyze the data. For example:

    *"Look at the sheet 'user queries'. Draw a graph of the total daily number of queries per day between the start of the year and now."*
  </Step>
</Steps>

### What You Can Do

- Generate charts and visualizations
- Calculate statistics and summaries
- Identify trends and patterns
- Create pivot tables and aggregations

## Support Ticket Resolution

If you're working with support tickets in tools like Zendesk or Freshdesk, you can ask Realm to suggest resolutions.

### How to Use

Simply paste a link to the ticket in chat, and Realm will:

1. Analyze the ticket content
2. Search relevant knowledge base articles
3. Suggest a resolution based on your company's documentation

  <img src="/images/help-center/support-ticket.png" alt="Support ticket resolution in Chat" />
</Frame>

<Tip>
This feature works best when you have comprehensive documentation and FAQs connected to Realm.
</Tip>

## Foreign Language Support

You can ask Realm questions in languages other than English.

### How It Works

- Realm searches for materials in the same language as your prompt
- Responses are provided in the same language as your query
- Cross-language search is also supported

### Optimization for Non-English Content

<Note>
If a significant share of your knowledge base is in a foreign language, have your admins inform the Realm team. We can make significant optimizations that improve Realm's performance in a given language.
</Note>

### Supported Languages

Realm supports queries in many languages including:

- European languages (German, French, Spanish, Italian, etc.)
- Nordic languages (Finnish, Swedish, Norwegian, Danish)
- Asian languages (Japanese, Chinese, Korean)
- And many more
