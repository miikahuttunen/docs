## Realm Chrome Extension

The Realm Chrome extension enables you to access Realm on any page and optionally open Realm as your new tab by default.

## Installation

Install the Realm Chrome extension from the [Chrome Web Store](https://chromewebstore.google.com/detail/realm/fdgpaflidjgjnijjdopfjaicfjpllkic).

## How to Use

### Keyboard Shortcut

Open the extension by pressing:

```
CTRL + SHIFT + K (Windows)
CMD + SHIFT + K (Mac)
```

<Note>
If you have another Chrome extension using the same keybind, you can change it:
1. Right-click the Realm Extension
2. Select "Manage Extension"
3. Go to "Keyboard shortcuts"
</Note>

### From the Extension Menu

Click the Realm icon in your Chrome extension menu to open it.

  <img src="/images/help-center/chrome-extension.png" alt="Chrome extension popup" />

### Address Bar Search

Use Realm directly from your browser's address bar:

1. Type `r` in the address bar
2. Press Tab or Space
3. Enter your query

## Chat vs Search

When you open the extension, you can choose between:

- **Chat** - Ask questions and get AI-powered answers
- **Search** - Find specific documents and files

## New Tab Override

You can configure Realm to open as your default new tab page.

### Enable/Disable New Tab

<Steps>
  <Step title="Open Realm Settings">
    Go to Settings in Realm.
  </Step>
  <Step title="Find New Tab Option">
    Look for the Chrome extension settings.
  </Step>
  <Step title="Toggle the Setting">
    Enable or disable the new tab override.
  </Step>
</Steps>

<Frame>
  <img src="/images/help-center/new-tab-setting.png" alt="New tab override setting" />
</Frame>

## Limitations

<Warning>
The extension does not work on Chrome's own pages, such as:
- New tabs (chrome://newtab)
- Settings (chrome://settings)
- Extensions page (chrome://extensions)
</Warning>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Extension not opening" icon="question">
    Check if you have a keybind conflict with another extension. Try clicking the extension icon instead.
  </Accordion>
  <Accordion title="Not logged in" icon="user">
    Make sure you're logged into Realm in your browser. The extension uses your existing session.
  </Accordion>
  <Accordion title="Address bar not working" icon="keyboard">
    After typing `r`, make sure to press Tab or Space before entering your query.
  </Accordion>
</AccordionGroup>
