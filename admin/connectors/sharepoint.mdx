## SharePoint Connector

Connect SharePoint to sync your documents and sites into Realm.

## Setting Up the Connection

<Steps>
  <Step title="Identify an Admin">
    Choose a Microsoft admin to perform the connection.
  </Step>
  <Step title="Connect SharePoint">
    Navigate to `https://[your-organization].withrealm.com/admin/connect?open=sharepoint` and click **Authorize**.

  </Step>
  <Step title="Accept Permissions">
    You'll see an OAuth consent screen. Click **Accept**.


    <Note>
    This won't start syncing any data yet.
    </Note>
  </Step>
  <Step title="Select Sites">
    After being redirected back to Realm, select which sites you want to sync.

  </Step>
</Steps>

## Required Scopes

The SharePoint integration requires:
- `Sites.Read.All`
- `Files.Read.All`
- `Directory.Read.All`
- `Notes.Read.All`

## Authentication Options

### Delegated Scopes (Default)

The default connection uses delegated scopes. Realm will only be able to sync documents that the account doing the connection has access to.

<Note>
Permissions are still enforced—users can only see what they have access to.
</Note>

### Application Scopes (Optional)

If you want to sync *all* available documents, click **"Connect with application permissions"**.


This allows Realm to access all documents in SharePoint. [Learn more about delegated vs application scopes](https://learn.microsoft.com/en-us/entra/identity-platform/permissions-consent-overview#delegated-access-access-on-behalf-of-a-user).

## Restricting Access

You can choose which SharePoint sites are synced in Realm. To further restrict API access:

1. Create a Microsoft service account that only has access to specific sites
2. Ensure the account can consent to applications
3. Use that account in the OAuth flow
