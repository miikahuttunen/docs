## HubSpot Connector

Connect HubSpot to sync your CRM data, activities, and content into Realm.

## Setting Up the Connection

<Steps>
  <Step title="Identify an Admin">
    Choose a HubSpot admin to perform the connection.
  </Step>
  <Step title="Ensure Access">
    Make sure the admin has the necessary permissions to access the HubSpot data you want to sync.
  </Step>
  <Step title="Connect HubSpot">
    Navigate to `https://[your-organization].withrealm.com/admin/connect?open=hubspot` and click **Authorize**.
  </Step>
  <Step title="Complete OAuth">
    You'll be redirected to HubSpot's OAuth flow. Log in if needed, then click **Connect app** to allow access.

  </Step>
  <Step title="Select Objects and Properties">
    After being redirected back to Realm, select which objects and properties you want to sync.

  </Step>
</Steps>

## Content Synced

### CRM Module

- Any Objects and Properties that you choose to sync
- Activities related to each object
- Attachments to Objects

### Content

- Knowledge Base articles

## Content Not Supported

| Category | Examples |
|----------|----------|
| Marketing data | Campaigns |
| Commerce data | Invoices |
| Reporting data | Dashboards |
| Library data | Templates |

## Selecting Objects

When configuring the connector, you can choose which HubSpot objects to sync:

- Contacts
- Companies
- Deals
- Tickets
- Custom objects

For each object, you can also select which properties to include.

## Best Practices

<AccordionGroup>
  <Accordion title="Start with Essential Objects" icon="list-check">
    Begin by syncing the most commonly searched objects (Deals, Companies, Contacts) and expand later.
  </Accordion>
  <Accordion title="Review Property Selection" icon="gear">
    Only sync properties that contain useful searchable content to keep your index clean.
  </Accordion>
  <Accordion title="Check Permissions" icon="shield">
    Ensure the connecting admin has access to all the data you want to sync.
  </Accordion>
</AccordionGroup>
