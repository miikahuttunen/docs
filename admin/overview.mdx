## User Management

As an admin, you can:

- Invite new users to your organization
- Manage user permissions and access levels
- Deactivate users who no longer need access
- View user activity and engagement

## Connector Management

Control which data sources are connected to Realm:

- Connect new workplace tools
- Configure sync settings and permissions
- Monitor sync status and health
- Manage which content is indexed

See the [Connectors documentation](/admin/connectors/overview) for detailed setup guides.

## Model Configuration

Decide which AI models your team can use:

- Enable or disable specific models (GPT-5, Claude, Gemini, etc.)
- Set default models for your organization
- Monitor model usage across your team

## Usage Analytics

Track how your organization uses Realm:

- Query volume and trends
- Most active users and teams
- Popular search topics and questions
- Agent usage statistics

## API Access

Create and manage API access tokens for integrations:

- Generate new API keys
- Revoke existing keys
- Monitor API usage
- Set rate limits

See the [API documentation](/api-reference/introduction) for more information.
